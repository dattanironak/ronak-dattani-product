- **Solve the core use case first.** Agree on the few workflows that matter and ship those well.

## Projects & case studies

### 1. QSR Voice AI Agent: talk to order, scan to pay
A voice agent takes counter orders, shows the cart live on screen, reads the order back and takes payment by UPI QR.

- Voice → UPI in one continuous flow · 3 services (agent, API, web) · 2 admin roles
- Stack: LiveKit Agents, LLM function tools, FastAPI, React, PayU UPI
- Code: [github.com/dattanironak/qsr-voice-agent](https://github.com/dattanironak/qsr-voice-agent)

### 2. Hospital Appointment Booking: one calendar for the clinic
Doctors set their hours and time off, staff book from a calendar showing only free slots, and patients get a WhatsApp confirmation.

- 0 double-bookings by design · 2 roles (admin, doctor) · WhatsApp confirmations
- Stack: Ruby on Rails, PostgreSQL, Twilio WhatsApp, RSpec, Render
- Code: [github.com/dattanironak/hospital-appointment-booking-system](https://github.com/dattanironak/hospital-appointment-booking-system)
